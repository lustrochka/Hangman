## 💀 Hangman

Enjoy the classic **Hangman** game and challenge your word-guessing skills!  
🔤 Guess the word, letter by letter, and try not to "hang" your character. 

## 🚀 Deployment

[Deploy](https://hangman-97a94e.netlify.app)

## 🎮 How to Play

In this version, you can use both virtual keyboard and physical keyboard to play.

- **Start the game**: A secret word is hidden under underscores, and you must guess the word by choosing letters.
- **Correct guesses**: When you guess a letter correctly, it appears in the correct position(s) of the secret word.
- **Incorrect guesses**: Each incorrect guess results in the appearance of one body part on the gallows. If all 6 body parts appear, you lose the game.
- **Win**: when the word is solved
- **Lose** if used all 6 attempts

A **"play again"** button will reset the game for a new round.

## 🔧 Installation and Setup

1. Clone the repository

```sh
  git clone https://github.com/lustrochka/rss-puzzle.git
```

2. Install NPM packages

```sh
  npm install
```

3. Start project

```sh
  npm run start
```
